# Initial Setup

Run the shell script named [setup.sh](setup.sh) in the ubuntu vm terminal.

Then make sure to do the following to run the script:

```bash
sudo chmod +x setup.sh
./setup.sh
```



Then do the following:

```bash
echo 'export PATH="$PATH:$HOME/.dotnet/tools"' >> ~/.bashrc
source ~/.bashrc
ilspycmd --version
```
